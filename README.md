# 火焰征程背景按鈕點擊工具

這是一個 Windows / Steam 遊戲用的本機工具。它會在指定的遊戲視窗中持續尋找
已加入的按鈕樣板；只要任一樣板出現，就會點擊該圖片中心。系統滑鼠游標不會被
移動或占用。

## 安裝與啟動

在本資料夾開啟 PowerShell：

```powershell
python -m pip install -r requirements.txt
python app.py
```

## 免安裝版本（Windows）

打包後的單一檔案位於 `dist/火焰征程背景點擊工具.exe`。朋友只要取得這個 `.exe`
即可執行，不需要安裝 Python。首次開啟可能需要幾秒鐘解壓縮；Windows SmartScreen
若顯示未知發行者警告，是因為此本機程式沒有程式碼簽章。

若要自行重新打包，請先執行：

```powershell
python -m pip install -r requirements-build.txt
.\build_exe.ps1
```

程式執行時產生的除錯圖片會存放在 `.exe` 同層的 `debug/` 資料夾，請將 exe 放在
具備寫入權限的位置（例如桌面或一般資料夾，不要放在 `Program Files`）。

啟動後會預先載入 `assets` 的五張按鈕樣板：`cancel_calibrated.png`、`finish.png`、
`manual_calibrated.png`、`ready_calibrated.png`、`start_calibrated.png`。取消、手動、
準備、開始都使用從實際遊戲畫面裁出的校正樣板；原始版本仍保留在資料夾中供自行加入。

## 使用方式

- **遊戲視窗**：按「重新掃描」後，從下拉選單選擇目前的遊戲視窗。程式會儲存其
  Windows 視窗控制代碼（HWND），因此遊戲在執行期間變更標題不會影響監控。
- **按鈕圖片清單**：清單內任一圖片出現即會觸發其設定好的固定位置點擊；可以加入或移除樣板。
  如果同一時間找到多張，程式會依清單順序點擊第一張；預設優先順序為取消、
  結束、手動、準備、開始。
- **固定點擊位置**：先選取清單中的按鈕，在 X／Y 欄位輸入點擊位置相對於遊戲客戶區
  的百分比，再按「儲存此按鈕位置」。辨識只用來確認哪一個按鈕出現，實際點擊會使用
  此固定位置。設定會儲存在 `button_positions.json`，並依校正時的視窗尺寸建立設定檔；
  相同尺寸下次校正時會自動載入。
  不知道百分比時，按「3 秒後擷取滑鼠」，在倒數期間把游標移到遊戲內的目標位置；
  工具會自動填入 X／Y，接著按儲存即可。
- **點擊重試**：同一張靜止不變的按鈕會先立即點擊；若畫面沒有變化，程式每 2.5 秒
  會重試一次。辨識到另一種按鈕或不同座標時，會立即改點新的按鈕。
- **掃描／點擊間隔**：每輪偵測及點擊後的最短等待時間。
- **定時停止監控**：勾選後輸入本機電腦時間（24 小時制 `HH:MM`），例如 `23:30`。
  開始監控後，程式會在下一個符合該時間的時間點自動停止，並在除錯紀錄顯示原因。
- **掃描速度與穩定性**：已校正的取消、手動／自動、準備、開始按鈕會在儲存的
  點擊位置附近，以原始解析度灰階比對；這能避開其他介面圖案，也較不受按鈕發光、
  色彩設定與動畫影響。其他自行加入的圖片仍採低解析度粗搜後原尺寸驗證。
- **相似度**：預設 0.80，校正按鈕會額外嘗試 ±2.5%、±5%、±10% 的細緻 UI 縮放比例。
  誤判時提高；辨識不到時可逐步降低至 0.70。若「自動」與「手動」是兩種不同外觀，
  請各自擷取一張當作樣板加入清單，不能只靠一張文字不同的樣板辨識另一種狀態。
- **開啟除錯視窗**：查看視窗搜尋、各樣板的最高辨識分數與點擊紀錄。勾選
  「偵測結果儲存除錯截圖」時，標註畫面會定期寫入 `debug/`。
- **校正目前解析度**：每次開啟工具後都必須先按一次。程式會讀取所選遊戲視窗的
  實體寬度，為取消、手動、準備、開始的校正樣板套用對應縮放比例，完成前不能開始監控。
- **儲存目前畫面**：優先透過 `PrintWindow` 擷取，若畫面是單色則自動改用 `BitBlt`
  擷取目前可見的遊戲視窗；結果會寫入 `debug/`，可用來檢查辨識來源。

若監控期間變更螢幕、DPI 縮放或遊戲視窗大小，請停止監控後重新按「校正目前解析度」。

## 已知限制

本工具使用 `PrintWindow` 讀取未聚焦的視窗，並使用 `WM_LBUTTONDOWN/UP` 送出背景點擊。
當 DirectX 遊戲拒絕 `PrintWindow` 時，會改用 `BitBlt`；此替代方式不需要遊戲取得焦點，
但遊戲視窗必須保持可見、不能被其他視窗完全遮住或最小化。部分遊戲、反作弊機制或
採用 Raw Input 的遊戲仍可能拒絕背景截圖或背景訊息。

請確認使用方式符合該遊戲的服務條款與帳號規範。
